# Claude Code Instructions

Lees en volg altijd eerst `AGENTS.md`.

## Extra regels voor Claude Code
- Onderzoek eerst de bestaande implementatie voordat je nieuwe patronen introduceert.
- Maak geen grote herstructurering zonder expliciete toestemming.
- Wijzig niet automatisch package-versies.
- Installeer geen nieuwe dependencies zonder toestemming.
- Gebruik bestaande services, models, controllers en UI-patronen waar mogelijk.
- Geef vóór implementatie een kort plan.
- Geef na implementatie een overzicht van alle gewijzigde bestanden en tests.
